# 큐브단면 스튜디오 (CubeSection Studio)

> **시중에서 구매 가능한 다양한 큐브의 단면(면별 단면, 층별 슬라이스 단면, 전개도)을 원하는 색으로 직접 채색하고, 고해상도 이미지 및 클립보드로 저장하는 전문 소프트웨어**

---

## 🌟 주요 기능

### 1. 시중 판매 큐브 전 라인업 지원
- **정규 N×N×N 정육면체 큐브군**: 1×1, 2×2(포켓), 3×3(정규 루빅스), 4×4(리벤지), 5×5(프로페서), 6×6, 7×7
- **WCA 공인 및 인기 이형 큐브군**: 
  - **피라밍크스 (Pyraminx)**: 4면체 정사면체 큐브
  - **메가밍크스 (Megaminx)**: 12면체 정십이면체 큐브
  - **스큐브 (Skewb)**: 코너 대각선 회전 큐브
  - **스퀘어-1 (Square-1)**: 슬라이스 변형 큐브
- **스페셜 큐브군**: 아이비 큐브(Ivy), 다이노 큐브(Dino), 플로피 큐브(1×3×3), 타워 큐브(2×2×3)

### 2. 3가지 단면 뷰 모드
- **면별 단면도 (Face View)**: 윗면(U), 앞면(F), 아랫면(D), 뒷면(B), 왼쪽(L), 오른쪽(R) 개별 단면
  - *특화 기능*: 루빅스 큐브 공식(OLL/PLL) 및 학습지 제작에 필수적인 **외곽 림(Rim) 표시** 토글 지원
- **층별 단면도 (Layer Slice Cross-Section)**: 1층(상층), 2층(중간층 E-슬라이스), 3층(하층) 등 큐브를 수평으로 자른 절단면 시각화
- **전체 전개도 (Unfolded Net View)**: 큐브의 모든 면을 2D 평면에 펼쳐놓은 십자형/다면체 전개도 단면

### 3. 실시간 3D 인터랙티브 큐브 뷰어
- 마우스 드래그로 360도 자유 회전 및 줌인/줌아웃
- **2D-3D 양방향 실시간 동기화**: 2D 단면에서 칠하면 3D 큐브에 즉시 반영되고, 3D 큐브 위를 클릭해 직접 칠할 수도 있습니다.

### 4. 강력한 색칠 & 편집 도구
- **다양한 컬러 팔레트**: WCA 공식 6색, 메가밍크스 12색, 문제 출제용 무채색/미정 색상, 사용자 커스텀 컬러 피커(모든 HEX/RGB 지원)
- **도구**: 브러시(붓), 페인트통(면 전체 한 번에 채우기), 스포이드(색상 추출), 지우개(초기 복원)
- **빠른 패턴 프리셋**: 기본 솔브 복원, 체커보드, 큐브 인 큐브, 도트(꽃잎), OLL 십자가, 백지화, 그레이스케일화
- **실행 취소(Undo / Ctrl+Z) 및 다시 실행(Redo / Ctrl+Y)** 무제한 지원

### 5. 고해상도 이미지 저장 & 클립보드 복사
- **📋 클립보드 복사 (Ctrl+V 즉시 사용)**: 버튼 한 번으로 캡처되어 한글(HWP), MS Word, PowerPoint, 노션 등에 바로 `Ctrl+V`로 붙여넣기 가능
- **고해상도 배율 선택**: 1x (일반 화면용), 2x (HD 보고서용), 4x (출판/인쇄용 Ultra HD)
- **배경 투명도 옵션**: 투명 배경 PNG, 흰색 배경, 다크 배경
- **포맷**: PNG, JPG, SVG(벡터 그래픽) 지원
- **종합 시트 저장**: 6개 모든 면 단면도를 한 장의 정리된 포스터/시트로 일괄 다운로드

## 🚀 실행 방법

### 방법 1. 원클릭 실행 (가장 추천)
폴더 내의 **`run_app.bat`** 파일을 더블 클릭하면 자동으로 로컬 웹 서버가 켜지며 기본 웹 브라우저에서 앱이 실행됩니다.

### 방법 2. 직접 열기
인터넷 익스플로러를 제외한 크롬, 엣지, 웨일 등 모던 브라우저에서 **`index.html`** 파일을 더블 클릭하여 바로 실행할 수 있습니다. (외부 인터넷 연결 없이도 오프라인에서 100% 작동)

## ⌨️ 단축키 안내

| 단축키 | 기능 |
| :--- | :--- |
| `Ctrl + C` | 현재 단면 이미지를 클립보드에 바로 복사 |
| `Ctrl + Z` | 실행 취소 (Undo) |
| `Ctrl + Y` | 다시 실행 (Redo) |
| `B` | 브러시 (단일 조각 칠하기) |
| `G` | 페인트통 (단면 전체 채우기) |
| `I` / `Alt+클릭` | 스포이드 (색상 추출) |
| `E` | 지우개 (기본색 복원) |
| `1` ~ `6` | 상단 팔레트 1번~6번 색상 빠른 선택 |
| `마우스 휠` | 단면 확대 / 축소 |
| `Shift + 드래그` 또는 `휠 클릭` | 화면 이동 (Pan) |
